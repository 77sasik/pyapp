4. (menu4 = WBS) (level1 ~ 7까지 프로세스를 계층적으로 관리할 수 있도록 동적 구성)(레벨, 프로세스 명, 단말여부, 가중치, 시작일자(계획), 완료일자(계획), 완료율(계획), 시작일자(실적), 완료일자(실적), 완료율(계획) 전체 달성률(완료율(실적)/완료율(계획), 달성률(별도 기준으로, -, 진행중, 완료, 지연 표기))
 - 합계{level7들의 가중치 * 완료율} = 상위레벨(level6)의 전체 완료율
 - 합계{level6들의 가중치 * 완료율} = 상위레벨(level5)의 전체 완료율
 - 합계{level5들의 가중치 * 완료율} = 상위레벨(level4)의 전체 완료율
 - 합계{level4들의 가중치 * 완료율} = 상위레벨(level3)의 전체 완료율
 - 합계{level3들의 가중치 * 완료율} = 상위레벨(level2)의 전체 완료율
 - 합계{level2들의 가중치 * 완료율} = 최상위레벨(level1)의 전체 완료율
 - 그리고 드래그앤 드롭으로 쉬운 관리가 되도록-> 이동해서 하위 혹은 상위레벨로 이동되면 해당 레벨에 맞게끔 레벨 및 상위 노드 등 자동 수정
 - 날짜 기준 진척률 자동 계산(계획/실적)
 - 계획 일정과 실적 일정 구분이 쉽게 각 일정들을 박스형태로 구성
 - 상위레벨(낮은 숫자의 레벨)의 진척률은 하위레벨의 진척률중 시작은 가장 적은 값, 종료는 가장 큰 값을 가져오도록 로직 반영
 - 버튼, 항목들이 2줄로 입력되지 않고 한줄로 입력되도록 전체적인 사이즈 조정(자식 추가 -> "+", 삭제 -> "-", 집계 완료율 -> 완료율 문구 변경)
 - 완료율은 (실적 완료율 / 계획 완료율) 을 계산하여 값 자동 계산하도록
 - 완료 여부는 IF(AB6 = 0, "-", IF(AND(Q6 <= $O$5, AB6 <1), "지연", IF(AB6 < 0.95, "지연", IF(X6 = 1, "완료", "진행중")))) 이 로직에 따라 자동 계산하도록
 - 완료율 쪽에 마우스를 올리면 첫번째줄은 실적 완료율: {실적 완료율 값}, 두번째 줄은 계획 완료율: {계획 완료율 값} 이렇게 보이도록 hover 설정
